# 1) 취업준비팀 — 신입 공고 수집 (매일)
대표를 위해 오늘 올라온 신입 채용 공고를 모아 Notion에 정리하고, 대표 결재함에 "오늘의 지원 추천 공고"를 올려.

### 수집 조건 (반드시 지킬 것)
- 신입 공고만. **인턴 공고는 제외.**
- 공기업: **일반사무직**(행정·사무 계열).
- 사기업: **대기업·중견기업만**. 직무는 인사, 총무, 대관, 대외협력 등 문과 계열 직무. **재무 직무는 제외.** 중소기업 제외.
- 다국적(외국계) 기업 중 위 문과 직무에 해당하는 신입 공고도 포함 (구분: 다국적 기업).
- 마감이 이미 지난 공고는 제외.

### 출처와 검색 방법
잡알리오(공공기관), 사람인, 잡플래닛, 인크루트, 링커리어.
- **출처마다 따로, 여러 번 검색해.** 최소 10번 이상. 예:
  - "site:job.alio.go.kr 신입 사무" / "잡알리오 신입 일반행정 채용 공고 마감"
  - "site:saramin.co.kr 신입 인사 대기업" / "사람인 신입 대외협력 공채"
  - "site:incruit.com 신입 총무 채용" / "site:linkareer.com 신입 대관"
  - "잡플래닛 신입 인사 채용", "하반기 신입 공채 인사 총무 마감 임박", "외국계 신입 HR 채용"
- 공고 페이지를 열 수 있으면 열어서 확인하고, 열 수 없으면(접속 차단 등) **검색 결과에 나온 제목·기업명·링크·마감일**로 판단해.
- 등록 기준: **기업·기관명, 공고 제목, 공고 링크(URL)** 가 확인되면 등록해. 마감일을 못 찾았으면 비워두고 메모에 "마감일 확인 필요", 직무를 확정 못 했으면 메모에 "직무 확인 필요"라고 적어.
- 신입 여부·인턴 여부·재무 직무 여부가 분명히 어긋나면 넣지 마. 애매하면 넣고 메모에 "조건 확인 필요".
- **링크는 검색 결과나 페이지에서 실제로 본 URL만.** 기업명·마감일·링크를 절대 지어내지 마.
- 로그인이 필요한 페이지는 쓰지 말고, 사이트에 부담 줄 만큼 대량으로 긁지 마.
- 같은 공고가 여러 사이트에 있으면 하나만 (원 공고 또는 가장 공식적인 링크).
- 목표: 조건에 맞는 공고를 **최대 15건**까지.

## 페이지 읽기 요령 (중요)
네트워크는 전체 허용이야. 그런데 WebFetch 도구는 일부 사이트(BBC·가디언 등)를 따로 막을 수 있어. **WebFetch가 막히면 Bash로 `curl -sL -m 20 -A "Mozilla/5.0" <주소>`를 써서 페이지를 받아 본문을 읽어.** 구글 뉴스 링크(news.google.com/rss/articles/...)는 원문 주소로 바꿔서 저장해 (curl -sIL로 최종 주소 확인, 안 되면 그대로 둬). 요약은 가능하면 본문을 읽고 써. 본문을 못 읽었으면 "제목 기준"이라고 표시해.
