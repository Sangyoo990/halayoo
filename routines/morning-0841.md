# 1) 취업준비팀 — 신입 공고 수집 (매일)
### 조건 (반드시)
- 신입·**정규직**만. **인턴·계약직 제외.** 공기업·공공기관은 **일반사무·행정직**. 사기업은 **대기업·중견기업만**, 인사·총무·대관·대외협력·**해외영업** 등 문과 직무. **재무 제외.** 중소기업 제외. 외국계(다국적)도 같은 문과 직무면 포함. 마감 지난 공고 제외.
### 출처 (우선순위)
1. **자소설닷컴** — 주력. 목록 페이지는 자바스크립트라 curl로 안 읽혀. **대신 달력 API를 써**:
   `curl -s -m 30 -A "Mozilla/5.0" -X POST -H "Content-Type: application/json" -d '{"start_time":"<오늘-1일>T00:00:00.000Z","end_time":"<오늘+30일>T00:00:00.000Z"}' https://jasoseol.com/employment/calendar_list.json`
   → JSON의 `employment` 배열: id, name(기업), title, start_time, end_time(마감), business_size(big_business=대기업 / middle_market=중견 / 없음), business_type(public_institution=공공), recruit_type. 최근 3일 안에 시작했고 마감 안 지난 것 중 조건에 맞는 것을 고른 뒤, 상세 페이지 **https://jasoseol.com/recruit/<id>** 를 curl로 열어 모집 직무(field)·신입/인턴 여부를 확인. 링크는 이 상세 주소로.
2. **링커리어** https://linkareer.com/list/recruit — 공고 목록·상세.
3. **잡알리오** https://job.alio.go.kr — 공공기관. 응답이 느리면 1번 재시도, 안 되면 건너뜀.
4. 보조: **사람인·인크루트** 검색 페이지 (curl로 열림. 예: https://www.saramin.co.kr/zf_user/search/recruit?searchword=신입+인사).
5. 참고: **공취사 등 네이버 취업 카페** — 로그인이 필요해 본문은 못 읽음. 웹 검색 결과의 제목·요약으로 "어느 기관·기업 공채가 떴다"는 소식만 참고하고, 등록할 때 링크는 위 사이트나 기업 공식 채용 페이지로 찾아서 넣어.
- 잡플래닛은 자동 접속 차단(403)이라 제외. 로그인 필요 페이지 사용 금지, 사이트에 부담 줄 만큼 대량 요청 금지.
- 등록 기준: 기업·기관명, 공고 제목, 공고 링크가 확인되면 등록. 마감일·직무를 확정 못 하면 메모에 "마감일 확인 필요"/"직무 확인 필요". 경영지원·본사관리처럼 범위가 넓은 직무는 상세 페이지에서 인사·총무·재무 중 무엇인지 확인해 메모에 적어 (재무만이면 제외).
- 같은 공고는 하나만. 이미 DB에 있는 공고(같은 링크 또는 같은 기업+공고명)는 다시 넣지 마. 목표 최대 15건.
### 부합도 판단 (취업준비 에이전트 8-3 절차)
- 오늘 새로 넣은 공고마다 상세 페이지의 자격요건을 대표 조건과 항목별로 대조해 **부합도 상/중/하**를 정해 (상: 필수 전부+우대 1개 이상 / 중: 필수 전부, 우대 없음 / 하: 필수 미충족 있음 — 미충족 항목명을 그대로). 자격요건이 이미지라 못 읽으면 [확인 필요].
- 목표 기관(2-2 목록: 인천국제공항공사·한국공항공사·부산항만공사·LH·부산교통공사·서울교통공사·한국농어촌공사·한수원·코레일·한국가스공사·한국조폐공사·한국중부발전·한국남동발전) 공고는 맨 위로, 잡알리오에서 이 기관들을 매일 따로 확인.
- 희망 지역(수도권·부산 > 대구) 밖이거나 1~3지망과 맞지 않는 직무는 비권장으로 표시하고 이유를 적어.
- 🎓 취업 자료실에 **"공고 부합도 판단 (M/D)"** 1건: 구분 "공고 부합도", 본문에 표(기관명/직무/필수요건 충족/미충족 항목/마감일/D-day/부합도/지원 권장) + 비권장 공고와 이유 + 마감 기준 준비 가능 여부 + 원문 확인 안내. 새 공고가 없으면 만들지 마.
### 저장
- 🎯 취업 공고: 공고명, 기업·기관, 구분(공기업/대기업/중견기업/다국적 기업), 직무, 마감일, 출처(잡알리오/사람인/잡플래닛/인크루트/링커리어/기타 — 자소설닷컴·카페는 "기타"), 링크, 수집일(오늘), 가산점·요건 메모, 상태 = "검토 전".
- ✅ 결재함: 오늘 새 공고가 있으면 안건 "오늘의 지원 추천 공고 (M/D)" 1건 (팀 취업준비팀, 구분 매일 결재, 상태 결재 대기). 오늘 안건이 이미 있으면 새로 만들지 말고 그 페이지에 추가. 내용: 추천 TOP 3와 이유, 구분별 건수, 마감 3일 이내 목록 (링크 포함).

### 매일 — 경험 정리 검토 · 가산점 점검 (취업준비 에이전트 기준)
- **경험 정리 검토 1건**: 0)의 PDF 4장 경험세트와 6장 점검 메모·7장 체크시트를 보고, 자료실에 아직 다루지 않은 주제 **하루 1개**를 골라 (순서 예: 6-5 국조실·행안부 경험 배치 → 6-1 국제처 문항 재작성 → 6-2 수치 자리표시자 → 6-3 → 6-6 → 경험 축 A~E별 문항 연결 → 장면 코드별 활용). 내용: 결론 먼저, 무엇이 문제인지(원문 vs 경험세트), 고칠 방향, 대표가 채워야 할 [ ] 항목. 원문 자소서를 고쳐 쓰지는 말고 방향과 근거만. 이미 같은 주제를 다룬 항목이 있으면 다음 주제로.
- 저장: 구분 "경험 정리 검토", 제목 "<주제> (M/D)", 출처 "취업준비 에이전트 — 통합본 <장 번호>", 링크 = 취업준비 에이전트 페이지 주소.
- **가산점 점검**: 오늘 새 공고들의 우대·가산점 항목을 대표 보유 자격(한국사 1급, TOEIC 920(2025.12 응시), KBS한국어 2-급, 컴활 2급 필기 합격·실기 11/20 응시 예정, 영어 스피킹 없음)과 대조해 "보유 / 미보유 / [확인 필요]"로 정리. 컴활 실기 결과처럼 PDF에 [ ]로 남은 건 지어내지 마. 새 공고가 없으면 건너뜀. 구분 "가산점·자격증".
