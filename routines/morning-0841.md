# 📮 대표 지시함 처리 (매번, 다른 업무보다 먼저)
- 📮 대표 지시함 (보기 https://app.notion.com/p/42301b1dbf7c8193a19fe3ff63b258ec?v=42301b1dbf7c819c8bfd000c5b029e9f , data source collection://42301b1d-bf7c-815e-a502-000b77b817da)을 view 모드로 읽어 **상태가 "접수"인 지시**를 오래된 것부터 모두 처리해. 지시 원문(제목)과 담당팀을 보고 그 팀 역할로 실제로 수행해: 웹 검색·페이지 열람(curl)·Drive 문서·Notion 자료를 써서 찾고, 읽고, 정리해.
- 결과물은 성격에 맞는 DB에 저장: 취업 관련 → 🎓 취업 자료실(맞는 구분), 공고 → 🎯 취업 공고, 소식·일반 자료 → 📰 일일 소식이나 결과 페이지, 국제 → 🌏 국제동향, 연구소모임·회의록 → 🔬 연구 소모임 (data source collection://0e7f410d-aa5f-484b-9a5d-c90a2df6df44). 맞는 DB가 없으면 지시함 항목 페이지 본문에 바로 써.
- 끝나면 그 지시 항목을 `notion-update-page`로 수정: 상태 "완료", 처리 결과 = 무엇을 했는지 2~3문장(결론 먼저), 결과 링크 = 만든 페이지 주소. 한 번에 끝낼 수 없는 큰 지시는 상태 "처리 중"으로 두고 처리 결과에 진행 상황과 다음 처리 시점을 적어. 지시가 모호하거나 권한·접속 문제로 못 하면 상태 "보류" + 이유와 대표에게 물을 질문 1개.
- **📎 첨부 파일**: 지시 원문에 "📎 첨부 파일 … asset id <ID> · Artifact 도구 read: url=…, path=<ID>"가 있으면, Artifact 도구 `read`(url = 적힌 오피스 아티팩트 주소, path = asset id)로 파일을 받아 끝까지 읽고 작업해 (PDF는 `pdftotext -layout`, 이미지는 직접 보기). 받지 못하면 그 지시는 "보류" + 처리 결과에 "첨부 파일을 열 수 없음 — Notion 지시함 페이지에 파일을 직접 올려 주세요".
- 지어내지 마: 확인한 사실과 출처만. 처리한 지시는 마지막 푸시에 "📮 지시 N건 처리 (완료 a · 보류 b)" 한 줄로.

# 1) 취업준비팀 — 신입 공고 수집 (매일)
### 조건 (반드시)
- 신입·**정규직**만. **인턴·계약직 제외.** 공기업·공공기관은 **일반사무·행정직**. 사기업은 **대기업·중견기업만**, 인사·총무·대관·대외협력·**해외영업**·**경영기획/전략**·**HRD(교육·인재개발)**·**HRM(인사운영·평가·보상·노무)** 등 문과 직무 (공기업도 같은 직무면 포함). **재무 제외.** 중소기업 제외. 외국계(다국적)도 같은 문과 직무면 포함. 마감 지난 공고 제외.
### 출처 (우선순위)
**원칙: 자동 접속을 막는 사이트(403, "보안 확인/안전한 접속 확인" 화면, Cloudflare 등)는 우회하지 말고 그날은 건너뛰어.** 브라우저인 척 헤더를 바꾸거나 다른 주소로 돌아가는 식의 우회 금지. 자소설닷컴·잡플래닛·캐치는 막혀 있으니 직접 접속하지 마.
1. **링커리어** https://linkareer.com/list/recruit — 공고 목록·상세.
2. **공공 채용 API (공공데이터포털, 환경 변수 `DATA_GO_KR_KEY`)** — 공공기관 공고는 **이걸 먼저**. 키 값은 어디에도 적거나 출력하지 마. 키 준비: `K=$(python3 -c 'import os,urllib.parse;print(urllib.parse.quote(os.environ["DATA_GO_KR_KEY"]))')`
   - **(가) 인사혁신처 공공취업정보 (승인됨)**: `https://apis.data.go.kr/1760000/PblJobService/getList?serviceKey=$K&numOfRows=100&pageNo=<N>&_type=json` → `response.body.items.item[]` 필드: `insttname`(기관), `title`(공고명), `regdate`·`enddate`(YYYYMMDD 숫자), `idx`(공고 번호), `areacode`, `type01`, `type02`, `readnum`. **오래된 순으로 쌓여 있으니** 먼저 numOfRows=1로 `totalCount`를 받아 마지막 페이지 N = ceil(totalCount/100)과 그 앞 1~2페이지만 조회해. `enddate`가 오늘 이후이고 조건(신입·정규직·사무/행정·목표 직무)에 맞는 것만 골라. 응답에 링크가 없으니 공고명으로 웹 검색해 **기관 공식 채용 페이지나 나라일터(gojobs.go.kr) 원문 링크**를 확인한 뒤 등록하고, 링크를 못 찾으면 메모에 "원문 링크 확인 필요"를 적어 등록. 공무원 시험 공고(공개경쟁채용시험 등)·기간제·인턴은 제외. 출처 = "기타"(메모에 "공공취업정보 API").
   - **(나) 공공기관 채용정보 (잡알리오 데이터, 승인됨 — 목표 기관 13곳은 여기서)**: `https://apis.data.go.kr/1051000/recruitment/list?serviceKey=$K&numOfRows=100&pageNo=<1..>&resultType=json&ongoingYn=Y` → `result[]`, 전체 건수 `totalCount`(진행 중 공고 약 550건 → 6페이지 정도, 전부 훑어). 필드: `instNm`(기관), `recrutPbancTtl`(공고명), `hireTypeNmLst`(정규직/비정규직 등), `recrutSeNm`(신입/경력/신입+경력), `ncsCdNmLst`(직무 분야, 예: 경영.회계.사무), `workRgnNmLst`(근무지), `pbancBgngYmd`·`pbancEndYmd`(접수 기간 YYYYMMDD), `decimalDay`(남은 일수), `aplyQlfcCn`(지원 자격), `prefCondCn`·`prefCn`(우대·가점), `acbgCondNmLst`(학력), `scrnprcdrMthdExpln`(전형 절차), `srcUrl`(원문 링크). **거르기**: `hireTypeNmLst`에 "정규직"(비정규직·무기계약 제외), `recrutSeNm`에 "신입", `ncsCdNmLst`에 사무·경영·행정 계열(재무·회계 단독 제외), 인턴·체험형 제외. 등록 시 링크 = `srcUrl`, 마감일 = `pbancEndYmd`, "가산점·요건 메모" = `aplyQlfcCn`·`prefCondCn` 요약(부합도·가산점 판단에 그대로 활용), 출처 = "잡알리오". 연결 오류(SSL 등)가 나면 30초 뒤 1번 다시.
   - 두 API 모두 안 되면 **잡알리오 사이트** https://job.alio.go.kr 로 (응답이 느리면 1번 재시도, 안 되면 건너뜀).
3. **사람인·인크루트** 검색 페이지 (예: https://www.saramin.co.kr/zf_user/search/recruit?searchword=신입+인사). 막히면 건너뜀.
4. **원티드** — 개별 공고 페이지 https://www.wanted.co.kr/wd/<번호> 만 열어 확인. 번호는 웹 검색(`site:wanted.co.kr/wd 신입 (HRD OR 인사 OR 경영기획 OR 전략기획 OR 해외영업 OR 대외협력)`)으로 찾기. 출처 = "원티드".
5. **웹 검색 + 기업·기관 공식 채용 페이지** — 웹 검색(`<직무> 신입 공채 2026 하반기`, `<목표 기관명> 채용 공고` 등)으로 공고 소식을 찾고, **기업·기관 공식 채용 사이트의 원문 링크**를 확인해 등록. 자소설닷컴·캐치·잡플래닛·공취사 카페는 검색 결과의 제목으로 "공고가 떴다"는 소식만 참고하고, 링크는 반드시 공식 채용 페이지나 위 1~4의 같은 공고로. 출처 = 처음 알게 된 곳(캐치면 "캐치", 그 외 "기타").
6. **목표 기관 13곳**은 매일 각 기관 공식 채용 페이지(또는 잡알리오)에서 새 공고가 있는지 따로 확인.
- 직무 속성 값: 일반사무 / 인사 / 총무 / 대관 / 대외협력 / 해외영업 / 경영기획·전략 / HRD / HRM / 기타 문과 (해당하는 것 모두). 출처 값에 "캐치"·"원티드"도 있으니 그대로 써.
- 로그인 필요 페이지 사용 금지, 사이트에 부담 줄 만큼 대량 요청 금지.
- 등록 기준: 기업·기관명, 공고 제목, 공고 링크가 확인되면 등록. 마감일·직무를 확정 못 하면 메모에 "마감일 확인 필요"/"직무 확인 필요". 경영지원·본사관리처럼 범위가 넓은 직무는 상세 페이지에서 인사·총무·재무 중 무엇인지 확인해 메모에 적어 (재무만이면 제외).
- 같은 공고는 하나만. 이미 DB에 있는 공고(같은 링크 또는 같은 기업+공고명)는 다시 넣지 마. 목표 최대 15건.
