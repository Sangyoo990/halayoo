# 1) 취업준비팀 — 신입 공고 수집 (매일)
### 조건 (반드시)
- 신입만. **인턴 제외.** 공기업은 **일반사무직**. 사기업은 **대기업·중견기업만**, 인사·총무·대관·대외협력 등 문과 직무. **재무 제외.** 중소기업 제외. 외국계(다국적)도 같은 문과 직무면 포함. 마감 지난 공고 제외.
### 출처 (우선순위)
1. **자소설닷컴** https://jasoseol.com/recruit — 주력. 공고 상세 페이지(jasoseol.com/recruit/번호)까지 열어 직무·마감 확인.
2. **링커리어** https://linkareer.com/list/recruit — 공고 목록·상세.
3. **잡알리오** https://job.alio.go.kr — 공공기관. 응답이 느리면 1번 재시도, 안 되면 건너뜀.
4. 보조: **사람인·인크루트** 검색 페이지 (curl로 열림. 예: https://www.saramin.co.kr/zf_user/search/recruit?searchword=신입+인사).
5. 참고: **공취사 등 네이버 취업 카페** — 로그인이 필요해 본문은 못 읽음. 웹 검색 결과의 제목·요약으로 "어느 기관·기업 공채가 떴다"는 소식만 참고하고, 등록할 때 링크는 위 사이트나 기업 공식 채용 페이지로 찾아서 넣어.
- 잡플래닛은 자동 접속 차단(403)이라 제외. 로그인 필요 페이지 사용 금지, 사이트에 부담 줄 만큼 대량 요청 금지.
- 등록 기준: 기업·기관명, 공고 제목, 공고 링크가 확인되면 등록. 마감일·직무를 확정 못 하면 메모에 "마감일 확인 필요"/"직무 확인 필요". 경영지원·본사관리처럼 범위가 넓은 직무는 상세 페이지에서 인사·총무·재무 중 무엇인지 확인해 메모에 적어 (재무만이면 제외).
- 같은 공고는 하나만. 이미 DB에 있는 공고(같은 링크 또는 같은 기업+공고명)는 다시 넣지 마. 목표 최대 15건.
### 저장
- 🎯 취업 공고: 공고명, 기업·기관, 구분(공기업/대기업/중견기업/다국적 기업), 직무, 마감일, 출처(잡알리오/사람인/잡플래닛/인크루트/링커리어/기타 — 자소설닷컴·카페는 "기타"), 링크, 수집일(오늘), 가산점·요건 메모, 상태 = "검토 전".
- ✅ 결재함: 오늘 새 공고가 있으면 안건 "오늘의 지원 추천 공고 (M/D)" 1건 (팀 취업준비팀, 구분 매일 결재, 상태 결재 대기). 오늘 안건이 이미 있으면 새로 만들지 말고 그 페이지에 추가. 내용: 추천 TOP 3와 이유, 구분별 건수, 마감 3일 이내 목록 (링크 포함).

# 2) 취업준비팀 — 취업 자료 (🎓 취업 자료실)
### 매일
- **취업 유튜브 2건**: 최근 2주 안에 올라온 공기업·사기업(문과 직무) 취업 전략, 채용 동향, 자소서 영상. **면접 기본기 1건**: 1분 자기소개, 지원동기, 인성·직무 면접 기본 질문 등 기초부터 하루 한 주제씩 천천히.
- 찾는 법: `curl -sL -A "Mozilla/5.0" "https://www.youtube.com/results?search_query=<검색어>&sp=CAI%253D"` (최신순) 결과에서 제목·채널·영상 ID를 뽑고 링크는 https://www.youtube.com/watch?v=<ID>. 이미 자료실에 있는 영상은 제외.
- 저장: 제목(영상 제목), 날짜(오늘), 구분("유튜브" 또는 "면접 기본기"), 요약(영상 제목·설명 기준 핵심 2문장 — 영상을 보지 못했으면 "설명 기준"이라고 적어), 활용 포인트(대표에게 왜 도움이 되는지 1줄), 링크, 출처(채널명).
### 매일 — 경험 정리 검토 · 가산점 점검
- 대표의 경험 자료: Notion **🗂️ 경험정리** DB (보기 주소 https://app.notion.com/p/1b901b1dbf7c815cb293fd690fe38fb9?v=1b901b1dbf7c819db39a000c10b8465c, view 모드로 읽기)와 **✍️ 자기소개서** DB (https://app.notion.com/p/1b901b1dbf7c81d68347d2b730f2beaa?v=1b901b1dbf7c8139bc3d000c8bb16fca).
- **템플릿 예시는 건너뛰어**: 기관(장소)에 "노션"·"Notion"이 들어간 항목(노션대학교·노션문고·노션카페·노션샵 등)과 제목이 마케팅(영업관리)·콘텐츠 마케팅·HRD·HRM·마케팅 (글로벌)·PM/AE/기획·자소서 작성 전 준비 과정인 자기소개서는 템플릿 예시라 대표의 실제 경험이 아님.
- 실제 경험이 있으면: 아직 자료실에 "경험 정리 검토"로 다루지 않은 경험 **하루 1개**를 골라 그 페이지(STAR)를 fetch로 읽고 → 수정 제안(문장·구성·수치화), 보충할 점(빠진 결과·근거·역할), 어울리는 자소서 문항·직무를 정리. 구분 "경험 정리 검토", 제목 "경험 검토 — <경험명>", 링크 = 그 경험 페이지.
- 실제 경험이 하나도 없으면: 자료실에 "경험정리 작성 필요" 안내가 이미 있으면 아무것도 하지 말고, 없으면 1건만 만들어 (구분 "경험 정리 검토", 요약 "경험정리 DB가 템플릿 예시뿐이라 검토할 실제 경험이 없음. 경험을 추가하면 다음 날부터 하루 1개씩 검토함").
- **가산점 점검**: 오늘 새로 등록한 공고들의 우대·가산점 항목(자격증·어학·한국사·컴활 등)을 모아 많이 요구되는 순으로 정리. 대표의 보유 여부는 모르면 "보유 여부 확인 필요". 구분 "가산점·자격증", 1건 (새 공고가 없으면 건너뜀).
### 목요일에만
- **합격 자소서 2건 분석**: 공기업·대기업 문과 직무, 최근 연도. 로그인 없이 공개된 합격 자소서(예: 링커리어·잡코리아 합격자소서 공개 페이지)만. 원문을 통째로 옮기지 말고 문항, 핵심 소재, 구성 방식, 대표가 쓸 때 참고할 점만 정리. 구분 "합격 자소서".
- **다국적 기업 검토 2곳**: 국내에서 문과 직무 신입을 뽑는(또는 자주 뽑는) 외국계 기업. 채용 현황·요건, 그리고 대표 경험(행정안전부 국제협력담당관실 청년인턴, 국제정세 주간 보고서 작성, 연구소모임 조장)이 강점이 되는 이유. 공식 채용 페이지 링크. 구분 "다국적 기업 검토".
